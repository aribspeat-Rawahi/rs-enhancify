# Rs Enhancify

Offline AI photo & PDF studio for Android.

- **AI Enhance** — Real-ESRGAN 2x/4x upscaling on-device (GPU or CPU), before/after slider
- **JPG to PDF** — multiple photos, reorder, A4/Letter/Fit, margins
- **PDF to JPG** — page ranges, 100/150/300 DPI
- **PDF to Word** — editable .docx (with offline OCR for scanned pages) or exact-layout mode

No internet permission. Files never leave the phone.
